# 體素三國 · Voxel Three Kingdoms

<p align="center"><img src="media/title.jpg" alt="體素三國 标题页：选将、选战场" width="100%"></p>

一款浏览器里就能玩的体素风三国割草动作游戏，基于 Three.js。五名武将、五处战场、一段五章的剧情，一人独闯数百敌军。

无需构建：纯 ES 模块，Three.js r186 已内置于 `vendor/three/`，逻辑以固定 60 Hz 确定性步进运行。

*A browser-playable voxel hack-and-slash set in the Three Kingdoms. Five officers, five battles, a story mode, archers, shield walls, cavalry and war horses, hundreds of soldiers. Plain ES modules, no build step.*

**官网 Site：<https://voxel-three-kingdoms.vercel.app>** · **直接开玩 Play：<https://voxel-three-kingdoms.vercel.app/play/>** · 作者 Author：[@sciencedegens](https://x.com/sciencedegens)

### 招式与无双

每名武将都有**自己的一套招式**：自己的连段长度、蓄力分支、判定和逐帧关键帧动作，以及**自己的无双**。赵云保留原作的枪法与青龙无双。其余四人的招式在 `src/heroes/*.moves.js`。

| 武将 | 普攻连段 | 蓄力 | 无双 |
| --- | --- | --- | --- |
| 趙雲 | 6 段枪法 | C1–C6 | 青龙冲阵 |
| 關羽 | 5 段重刀：斜撩、劈砍、横斩、回旋、跃斩（带青龙月牙） | 青龍斬 / 挑斩 / 旋风 / 三连月牙 / 跃劈破地 | 青龍偃月・天斬：拖刀冲锋、巨斩、回旋，落地一圈月牙 |
| 張飛 | 6 段蛮力：刺、进步刺、抡扫、肩撞、下砸、头顶舞矛接跺地 | 當陽一喝接挑刺 / 冲刺挑 / 连刺 / 双旋 / 跃起跺地 | 燕人咆哮：一喝震退、冲锋、乱刺、跺地裂地 |
| 諸葛亮 | 6 段羽扇：每下都甩出风刃，第 5 段是光束，第 6 段是八刃环 | 光束 / 旋风挑空 / 边退边连射 / 旋转刃环 / 天降光柱 | 東風・八陣：东风起、八向光束、光柱行进、刃雨、光环 |
| 呂布 | 6 段快攻：快斩、反斩、上撩、跳旋、双旋、跃砸（带赤月牙） | 天下無雙 540° 扫 / 挑空 / 突刺穿阵 / 龙卷 / 跃刺 | 天下無雙・神鬼亂舞：之字形连续突进，最后十二道赤月牙 |

四人的蓄力起手时，兵器上会聚起本人颜色的光；刀光轨迹、无双龙、喊声音色、打击震屏也各不相同。跳起后连按普攻是各自的三段空中连斩，待机、跳跃、落地、受击姿势也是各自的。

### 敌将与平衡

武将不再是无敌的：
- 杂兵的攻击会打断普通连段，只有带霸体的招式（蓄力、终结技、吕布的全套）能顶着打。
- 敌将会正面格挡轻攻击，被挡时有金属声和火花；蓄力、重击和无双可以破防，连续格挡三次也会被打破。
- 敌将被连招锁住、受到的伤害到一定比例时，会霸体挣脱并立刻反击，所以连招要留空间，或者先闪避。
- 吕布有架势条：被打出硬直时是输出窗口，起身后 2.5 秒内不会再硬直。

### 兵种

敌军不再只有一种杂兵：
- **弓兵**（背着箭袋）：在 10–15 米外放箭，你一靠近就后退。拉弓时箭头会发白光，放箭前一刻变红。箭只扣血，不会打断你的动作。翻滚可以躲开，迎面挥砍能把箭斩落。
- **大盾兵**（举着高大的方盾）：正面挡住普通攻击，连续挨到第三下才会破防。蓄力攻击、无双、从侧面或背后打都能直接命中。营寨的守军前排就是盾墙，后面站着弓兵。
- **骑兵**：成队冲锋，从你身上踏过去会把你撞飞，然后兜回来再冲。普通攻击只能扣血，把他打下马要用蓄力攻击、跳跃攻击或无双。落马的骑兵会下马步战，留下的空马可以骑。每隔一段时间会有一队骑兵从敌营或远处杀来（长坂坡是曹操的虎豹骑，来得最频繁；黄巾军没有骑兵）。

### 战马

- 按 **U**（手柄 L1，触屏「馬」键）召唤自己的战马。马从镜头后方跑来，到你身边时自动上马。赵云骑白马，关羽、吕布骑赤兔，张飞骑黑马。
- 骑马时速度可达 15 米/秒，正面冲进步兵堆会把他们撞翻。马上按 J 连续挥砍，按 K 是大范围的终结横扫。
- 被弓箭或杂兵打中只扣血；被敌将、吕布或敌方骑兵重击会摔下马。放无双时会自动下马。
- 再按一次 U 下马，马会留在原地等你。靠近敌人留下的空马按 U，也能直接骑上去。

### 补给

每个战场有 16 个可以打碎的陶罐和补给箱，敌将和杂兵也会掉落：

| 补给 | 效果 |
| --- | --- |
| 肉包 / 大肉包 | 回复体力 80 / 220 |
| 酒 | 无双槽 +1 格 |
| 虎符 | 攻击力两倍，25 秒 |
| 玄甲 | 防御力两倍（受伤减半），25 秒 |
| 寶箱 | 一件装备，直接放进武库 |

### 装备与等级

每位武将都有等级（1–50），击破敌兵和敌将、通关评价都会给经验；升级后体力、攻击和防御都会成长。标题页的「武库」可以给当前武将换装：
- **武器**（每位武将专属）：五种稀有度，从凡、良、精、神到传说（金色传说即各自的名器，如青龍偃月刀、方天畫戟）。武器带攻击加成，以及最多 3 个属性：炎、冰、雷在蓄力攻击时触发；斩（几率三倍伤害）、吸（伤害转体力）、无（无双积攒加快）对所有攻击生效。
- **宝物**两格（任何武将都能用）：体力、受伤减免、无双、补给回复、移动速度、攻击。
- 敌将有几率掉宝箱，总大将和吕布必掉更好的宝箱；难度为「难」时掉落更好。

进度保存在本机浏览器里。

### 生死与结算

血条打空就会战死，弹出结算（击破数、最大连击、时间），可以再战或回到选将。击破敌将必掉一个肉包，每击破 40 个小兵也会掉一个，走过去就能回血。

完成战场的最后一个目标就是「勝利」：按通关时间、击破数和受到的伤害给出 **S / A / B / C 评价**，每位武将在每个战场的最佳纪录保存在本机（标题页的战场卡片上会显示最佳评价）。

标题页可以选**难度**（易 / 普通 / 難：影响敌人伤害、敌将和 Boss 的血量、出手频率）和**画质**（自动 / 高 / 中 / 低）。自动画质在帧率持续低于 40 时会自动降一档，并记住结果。

## 战场

| | | |
| --- | --- | --- |
| ![长坂坡](media/changban.jpg) | ![虎牢关](media/hulao.jpg) | ![赤壁](media/chibi.jpg) |
| **長坂坡** · 黄昏 · 魏军 | **虎牢關** · 白昼 · 董卓军 | **赤壁** · 夜战火攻 · 曹军 |

另有 **黃巾之亂**（清晨 · 黄巾军，头裹黄巾，可砸毁三座黄巾祭坛）和 **樊城**（秋雨 · 魏军，雨中的汉水与长堤，掘开堤坝后水淹七军）。

每处战场有自己的天空、光照、画面风格、敌军旗号与军服颜色、敌将阵容，部分武将还有专属开场台词（比如虎牢关的关羽：「溫酒之間，斬汝華雄！」）。

每处战场半径约 92 米，四周的营寨、河流、城墙随之铺开。战场上分布着五座敌军**据点（营寨）**：
- 营中有守军，靠近就会出击；附近的敌军援军也从营里杀出。
- 在营中击破守军，营寨的「守备」降到零时，**据点兵长**就会现身；打倒他，营寨即被攻占，旗帜换成我军颜色，敌军援军随之减少。
- 按 **M** 或点击小地图，可以查看整张战场地图：营寨、目标、自己的位置。
- **疾走**：朝一个方向持续奔跑约 1.5 秒后自动提速到 1.35 倍，视野也会略微拉宽；停下、攻击、闪避或急转身都会打断。

每处战场都有一串**目标**（右上角目标栏、屏幕边缘的方向箭头、小地图标记），一章大约 7–8 个目标，全部完成即胜利：

| 战场 | 目标 |
| --- | --- |
| **黃巾之亂** · 桃園初陣 | 击破程远志 → 攻破两座黄巾营 → 击破邓茂 → 砸毁三座黄巾祭坛 → 扫荡两翼营寨 → 击破张宝、张梁 → 攻入黄巾本营 → 讨伐天公将军张角 |
| **虎牢關** · 三英戰呂布 | 斩华雄 → 攻破关前两营 → 击破李傕 → 攻破左翼营 → 击破郭汜 → 攻破最后两营 → 吕布出关（玩家是吕布时换成关羽） |
| **長坂坡** · 單騎救主 | 击破夏侯恩（夺得青釭剑）→ 突破曹军前营 → 在废村中搜寻阿斗 → 到枯井边救出阿斗 → 击破晏明、淳于导 → 杀出重围（攻破两营）→ 击破南路的张郃 → 突破至长坂桥，张飞一声断喝「燕人張飛在此！」 |
| **赤壁** · 火燒連環 | 击破蔡瑁 → 攻破岸上两营 → 击破张允 → 攻破中营 → 在岸边点燃三艘火船 → 火烧两座水寨 → 击破于禁 → 击破曹仁，曹操败走华容道 |
| **樊城** · 水淹七軍 | 击破董衡 → 攻破两营 → 击破董超 → 攻破七军大营 → 掘开汉水三道堤坝，洪水横扫战场 → 击破于禁 → 斩庞德，威震华夏 |

- **虎牢關**：两侧岩壁夹道，一路收窄到关门。斩华雄、击破李傕与郭汜之后，**吕布**从关前杀出，这就是「三英戰呂布」。他有独立血条和霸体，会用三种有预警的招式：地面先亮起红色警示圈或突刺线路，然后打出旋扫、突刺或跃击；打掉他的架势条可以让他硬直。如果玩家选的是吕布，杀出来的就换成**关羽**。
- **赤壁**：战场后方是一条大江，江面上泊着用铁链相连的曹军战船（連環船），多艘正在燃烧，火光映在水面上。

## 运行

ES 模块无法通过 `file://` 加载，请用任意静态服务器托管此目录：

```sh
python3 -m http.server 8000
```

然后打开 http://localhost:8000 。需要支持 WebGL2 的浏览器。手机和平板可以横屏用触屏玩；电脑上推荐键盘加鼠标，并打开声音。

### 部署

线上版本用的是打包版：`npm i` 之后运行 `npm run build`，把整个游戏打包成一个压缩并带内容哈希的 `game-<hash>.js`，加上 `index.html` 和资源文件放在 `/play/` 下；网站根目录是官网（`site/`：首页、截图、宣传短片、标题字体），输出为 Vercel 的 prebuilt 格式（`.vercel/output`）。旧链接 `/?stage=…&hero=…` 会自动跳到 `/play/`。`npm run deploy` 会先打包，再执行 `vercel deploy --prebuilt --prod`。源码目录不经打包也能直接运行（本地开发时游戏就在根目录）。

## 目录结构

```
index.html      入口、importmap、HUD 与标题页样式
src/heroes/     每名武将一个文件：模型、兵器、弹簧链、头像、台词、战斗风格
src/stages/     战场配置：天空、光照、敌军、台词、布景、Boss、目标脚本（campaign.js）与目标道具（props.js）
src/boss/       Boss 模拟与表现（虎牢关 三英戰呂布）
src/horse/      战马：体素模型与步态（model.js）、空马与召唤（horses.js）；骑乘逻辑在 src/hero/mount.js
src/            core、hero、combat、crowd、musou、camera、vfx、post、world、audio、ui
vendor/three/   Three.js r186
site/           官网：index.html、img/（截图与立绘）、media/（宣传短片）、fonts/（标题书法字体 Yuji Boku 子集，OFL）
tools/          build.mjs（部署打包：官网 + /play/ 游戏）、record/（宣传片录制）、tape/（链上包）
```

新增武将：在 `src/heroes/` 仿照现有文件写一个定义（`build()` 返回各关节的体素块，`chains()` 返回飘动部件），再加进 `src/heroes/index.js`。自己的招式写在 `*.moves.js`：`moves()` 招式表、`clips(A, M)` 用 `src/hero/anims/author.js` 逐帧写动作、`musou` 无双脚本。
